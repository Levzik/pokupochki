# Автоматическая синхронизация с GitHub (Auto Git Sync)

## Строгое правило рабочего пространства «Покупочки»

1. **Всегда сохранять изменения в GitHub**: При любом редактировании, добавлении или удалении файлов в проекте (компоненты React, стили Tailwind, скрипты, настройки, Android-файлы) агент ОБЯЗАН в конце каждого ответа выполнить:
   ```powershell
   git add .
   git commit -m "<Четкое описание изменений>"
   git push origin main
   ```
2. **Проверка успешности отправки**: Убедиться, что `git push origin main` завершился с кодом 0 и ветка `origin/main` актуальна.
3. **Никогда не оставлять локальный рассинхрон**: Все новые фичи, фиксы и правки должны сразу быть сохранены в удаленном репозитории пользователя `Levzik/pokupochki`.
